## 2. DATA-01 walk_diag 体系明细（重点资产）

**架构**（为 1kHz 实时循环设计，观测不干扰控制）：
- 实时核侧：`Update()` 每 10 周期置 `diag_pending_frame_`（`rl_controller.cc:253-259`，decimation=10 → 100Hz），`GetJointCmdData()` 末尾 `EnqueueDiagFrame()` 入 SPSC 环形缓冲（容量 256，atomic 无锁，`rl_controller.cc:16,469-537`）
- 落盘侧：独立 LoggingWorker 线程 1ms 轮询 `DrainDiagBuffer()`，200ms flush（`rl_controller.cc:201-248`）

**自动生命周期**：状态机切 RL walk 态开新文件（触发链 `control_module.cc:183-203` UpdateRlLoggingState → SetLoggingActive）；停写 500ms / 写满 2000 帧（20s@100Hz）/ 进程退出 / IO 错误 → 自动关闭并打印 frames/dropped 摘要。

**字段**（header 生成 `rl_controller.cc:621-653`；历史数据实测核对）：

| 组 | 字段 | 备注 |
|---|---|---|
| 时间/指令 | timestamp_ns、phase_sin/cos、cmd_linear_x/y、cmd_angular_z | timestamp_ns 为 `high_resolution_clock`（steady），跨体系对齐见 D0 索引 §3 |
| 基座 | base_euler×3、base_ang_vel×3、imu_quat/gyro/accel ×10 | 可复用为 D5 摔倒判定 |
| 每关节 ×9 | action、pos、vel、effort、pos_des_raw、pos_des_lpf、tau_des_raw、tau_des_lpf、is_parallel | des 双份可分离 LPF 滞后 |
| 策略/执行器 | clip_count、actuator_cmd_effort（仅并联踝）、actuator_state_effort（全腿） | **串联关节 cmd effort 列恒 0**（`rl_controller.cc:714`），力矩跟踪用 kp·pos_des−kd·vel 换算 |

**历史数据**：`motion_control/czy/8.7/walk_diag_20260807_093740.csv`（1271 帧，间隔均值 9.9996ms，max 15.5ms）；旧格式 `czy/real_data/`（2026-08-04，含 contact 列、无执行器列）。

## 6. R3/R4/R5 统计文件格式（2026-09-01 实施）

**设计约定**：RT 循环内仅 O(1) relaxed 原子/直方图更新（无锁无 IO）；非 RT 线程（ErrorHandler / ctrl_stat_w worker）每 10s 读出清零落 CSV；**数据只落文件不打印终端**；每行带双时间戳（wall_ts + steady_ns，对齐 D0 索引 §3 时钟源决策）。

### 6.1 `test_logs/ecat_stats/ecat_stats_*.csv`（R3/R4，ErrorHandler 线程写）

```
wall_ts,steady_ns,dc_cnt,dc_dev_avg_ns,dc_dev_abs_min_ns,dc_dev_abs_max_ns,
cycle_cnt,cycle_late_avg_ns,cycle_late_max_ns,cycle_overruns,wkc_bad_polls
```

- `dc_dev_*`：每周期瞬时 DC 偏差 `dev = (ec_DCtime 增量) − cycle_time_ns`（avg 有符号可看漂移方向，min/max 取绝对值）；DC 关闭时 dc_cnt=0 列为空
- `cycle_late_*`：调度迟到（唤醒 − sleep_until 目标）；**overrun 阈值 = 迟到 > 周期/5（1kHz 下即周期 >1.2ms）**，S1 基线后校准
- `wkc_bad_polls`：10s 窗口内 WKC 异常轮询数
- 落点随 aimrt_main 工作目录（与 walk_diag 同约定）

### 6.2 `test_logs/data_csv/ctrl_period_*.csv`（R5，ctrl_stat_w 线程写）

```
wall_ts,steady_ns,samples,
late_us_p50,late_us_p95,late_us_p99,late_us_max,miss_cnt,
body_us_p50,body_us_p95,body_us_p99,body_us_max,
late_over_cnt,body_over_cnt
```

- `late_us_*`：唤醒延迟（调度抖动）；直方图 32 桶 × 10µs（覆盖 0–320µs，超出计入 late_over_cnt）
- `body_us_*`：每周期体耗时（Update+publish）；直方图 32 桶 × 20µs（覆盖 0–640µs）
- **miss 阈值 = late ≥ 100µs**（初值，S1 基线后校准；D1 Q3 判定"10min<10 次"= 60 行 miss_cnt 求和 <10）
- 分位数由直方图估计，粒度 = 桶宽
