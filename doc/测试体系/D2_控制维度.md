## 1. 目标与链路定位

量化链路后半段的执行质量：`/joint_cmd → dcu_driver → EtherCAT → 电机驱动器 → 电机 → 反馈`。含两个子维度：

1. **EtherCAT 总线质量**：WKC 丢帧、DC 同步偏差、总线周期 overrun；
2. **电机执行质量**：关节跟踪误差、执行滞后、力矩饱和、增益下发正确性。

**双源交叉原理**（隔离通信/执行贡献）：walk_diag（DATA-01，进程内直采，误差含通信+执行）与 actuator 话题对（DATA-04，dcu 同循环采集，近似纯执行）——两者误差之差 ≈ 通信层贡献。

## 3. EtherCAT 总线质量判定（WKC 丢帧 = 一票否决）

```bash
grep -c "wkc < expected_wkc" $RUN/aimrt_journal.log   # 告警次数（100ms 粒度）
grep -c "Ecat link lost"      $RUN/aimrt_journal.log  # 完全失联次数
grep    "Ecat link resmed"    $RUN/aimrt_journal.log  # 恢复时刻
```

读法：
- 告警 0 → PASS；
- 告警 >0 但无 link lost → 记录次数与时刻对比 S1（S1=0 而 S2 出现 → 大脑负载干扰总线，查 IRQ 亲和是否落到 CPU0）；
- link lost ≥1 → FAIL，先修硬件，与资源判定无关。

DC 同步偏差与总线周期 overrun（MOD-05/06）**已实现**（R3/R4，2026-09-01）：每 10s 一行落 `test_logs/ecat_stats/ecat_stats_*.csv`（格式与阈值见实现索引 §6）。阈值沿用配置指南（DC <1µs 基线 / <5µs 加载；overrun 参考 10min<10 次）。

## 4. 电机执行分析手册

> S1 与 S2 对比是关键：S1 的值即硬件底噪，S2 相对 S1 的退化才是"大脑上机的影响"。主数据源 DATA-01（100Hz，des 双份），DATA-04 补 1kHz 盲区；两者按帧序号配对。

### 4.1 位置跟踪误差（τ 对齐后残差）（核心）

> **口径（2026-09-04 修订）**：行走频率下"同帧相减"的误差主要来自**滞后相位项**而非幅度缺陷——关节运动近似正弦时，同帧误差 ≈ A·ω·τ，与速度成正比（A=0.4rad、f=1.5Hz 时仅滞后 13ms 的同帧 RMS 即达 0.05 rad 判决线，而幅度跟踪可以完全正常）。因此本指标定义为**先按 §4.2 测滞后 τ、插值对齐后相减的残差**；未对齐的同帧误差不作本节判定值，仅用于 S1/S2 相对对比（系统性滞后在两次测量中同量级，差值仍有意义）。
>
> walk_diag 的 des/pos 为同控制周期**进程内直采**（单一 steady 时钟、无 DDS/网络环节）——跨体系时钟偏移与 DDS 抖动不进入此链路；实际污染源仅两类：EtherCAT 周期量化（~1ms，缓变，由对齐吸收）与电机/驱动器动态滞后（**随步态相位/负载缓变，非逐样本随机**，按下面的分相位读法处理）。

```
① 整段互相关求 τ_j（§4.2；100Hz 裸分辨率 10ms 过粗——对相关峰抛物线插值，或用 DATA-04 1kHz 对算）
② pos 序列按 τ_j 插值平移后相减：
e_j[k] = pos_des_lpf_j[k] − pos_interp_j[k + τ_j]       # 对齐后残差，统计 mean/RMS/P95/max
walk_diag 对应列: pos_des_lpf_<joint> vs pos_<joint>（并联踝用 tau_des_lpf 换算）
③ τ_j 单独按 §4.2 判定并报告（τ 大=驱动器带宽/kp·kd 问题；τ 正常而残差大=幅度缺陷/饱和——处置路径不同）
```

| 关节组 | RMS | P95 | 备注 |
|---|---|---|---|
| 髋/膝（R86 系） | <0.05 rad | <0.10 rad | 串联结构 |
| **踝（并联，2 执行器/侧）** | <0.10 rad | <0.20 rad | 硬件画像已知"踝并联响应不一致"，单独放宽并重点观察左右不对称 |
| 腰/腕（R52） | <0.05 rad | <0.10 rad | — |

读法：S1 先记底噪；S2 行走中 RMS 相对 S1 >3× → 执行层退化（多伴随 D1 Q3 FAIL）；左右踝误差不对称 → 并联结构不一致的量化证据。

**分相位读法**：walk_diag 自带 phase_sin/cos 列，按步态相位分片统计 τ(φ) 与残差(φ)——支撑相（负载大）与摆动相的滞后差即"滞后随负载变化"的量化特征；S1/S2 同为吊装空走，系统性滞后在对比中相消，剩余退化即大脑上机的影响。

### 4.2 执行滞后

对每关节 cmd 与 state 位置序列做互相关，峰值对应滞后 τ。**τ 是 §4.1 对齐相减的前置输入**（相关峰抛物线插值取分数 τ；或用 DATA-04 1kHz 序列对算获 ms 级分辨率）。判定 <5ms（1–5 个 1kHz 周期）。τ 在 10–30ms 量级 → 驱动器滤波/带宽不足或 kp/kd 过低；τ 随负载增大 → CPU 侧发布延迟增大（应伴随 D3 §4.2 尖峰）。

### 4.3 力矩跟踪与饱和

按电机规格分组（规格与关节映射见实现索引 §4）：

```
duty_peak  = count(|effort_state| > 0.9×峰值) / 总帧数     # 判定 <1%
duty_rated = count(|effort_state| > 1.0×额定) / 总帧数      # 判定 <10%（短时超额定=步态冲击正常）
```

同时对比 cmd effort vs state effort：指令 50Nm 反馈 20Nm → 驱动器限流或力矩常数问题。注意 walk_diag 中串联关节 cmd effort 列恒 0（实现索引 §2），需用 kp·pos_des−kd·vel 换算。

### 4.4 增益下发验证

抽取 walk 区间 3 帧，核对 /actuator_cmd 的 stiffness/damping（实际下发 kp/kd）与期望增益表一致，无 0 值异常（idle/zero 态 kp=0 正常，只在行走区间核对）。

### 4.5 综合定位表

| 现象 | 大概率层 | 证据组合 |
|---|---|---|
| WKC 告警 + 周期性误差尖峰 | EtherCAT | §3 告警时刻 vs 误差尖峰对齐 |
| /joint_states 延迟尖峰 + 误差尖峰 | DDS/调度 | D3 §4.2 与误差序列对齐 |
| 延迟正常但跟踪差、τ 大 | 驱动器/电机 | §4.2 τ 大 + D3 §4.2 正常 |
| 力矩饱和 + 跟踪差 | 选型/步态 | §4.3 duty 高 |

## 7. 局限

1. walk_diag 仅 RL walk 态记录——stand/空载态无数据（S1 基线场景没有 walk_diag，需靠 DATA-04 bag）。
2. 100Hz 采样，亚 10ms 瞬态（单帧 WKC、DDS 尖峰）不可见——需 DATA-04（1kHz）补充。
3. 串联关节 cmd effort 列恒 0，力矩跟踪需换算（见 §4.3）。
4. 20s/文件 + 500ms idle 即断，长行走多文件需拼接。
5. WKC 告警为 100ms 粒度，单帧丢包不可见，只能看趋势计数。
6. 电机温度/母线电流无话题（G7），力矩饱和只能用 effort 间接判断。
