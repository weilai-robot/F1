# D4 安全维度 — 故障注入与失效安全

## 目标（方案展开前的边界定义）

1. **大脑任意失效 → 机器人安全停止**：导航进程崩溃/被 kill、Livox 断链、FastLIO 漂移发散、Nav2 卡死，任一发生时小脑在限定时间内降级为安全停步（零速 + 站立/缓降），不失控、不摔倒、不继续行走。
2. **指令通道失效 → 安全响应**：`/cmd_vel` 断流、异常高频、超幅/超速指令，小脑按新鲜度看门狗与限幅规则处置（看门狗实现需求由 D3 §7 提出，本维度负责验证其行为）。
3. **小脑自身失效 → 已知降级行为**：EtherCAT 断链（WKC lost）、驱动器异常退出，机器人的行为（掉电阻尼/锁定/缓降）已知且经过一次实机验证。
4. **急停优先级最高**：硬件急停可在任意软件状态/任意故障叠加下中断一切，且急停后的软件状态机可恢复。
5. **每一项失效都有测试用例**：故障注入清单 + 预期行为 + 判定标准 + 安全前提，形成可回归的测试集（吊装下执行）。
