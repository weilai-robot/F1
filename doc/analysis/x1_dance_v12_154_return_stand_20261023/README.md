## 检查与失败记录

- 独立 Clang C++20 + ASan/UBSan 检查通过：固定目标、姿态不到位不能确认、支撑/静止连续门控、失去支撑后的目标与增益连续、重复时间戳、限位/上身目标限速、时钟/倾角故障。

- Python 语法和 `git diff --check` 通过。部署权重与上一版相同，来源哈希在 `validation.json`。
- `candidates_2s/yawm1p2.json` 和前后向 60 N 两份 JSON：2 秒动态混合在部分场景发生失稳，最终延长为 4 秒后通过上述同类场景。
- `candidates_2s/yaw0_fixed_start.json`：2 秒固定起点插值提前移除 AMP 反馈修正，未通过。最终方案在整个渐变中逐步交权。
