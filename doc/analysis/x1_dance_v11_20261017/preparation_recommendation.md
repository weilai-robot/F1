# X1 v11 dance 准备位推荐与对比

结论：当前优先选训练 `default_q`。准备阶段沿用高增益 PD（腰 500/5，腿 300/5，臂腕 80/1.5），4 秒线性过渡。当前一次 Guide 启动准备，连续就绪等待 4 秒后自动切舞蹈辨识 PD 与 50 Hz ZOH。所有结果来自 Mac / MuJoCo 3.14.0 / 训练 MJCF / 理想状态反馈，未运行 Ubuntu C++ 或真实 DCU。

## 筛选方法

对每个候选先执行 stand 驻留、4 秒姿态过渡、静止保持，再从参考帧 0 进行完整单次播放。没有修改原始模型、动作、PD 辨识参数或放宽原有保护。候选实验临时用其自己的准备目标做 Guide 到位校验；这些实验文件带 `experimental_candidate_entry_gate: true`，不等同于直接执行当时的 C++ 配置。最终 default_q 已写入生产配置，并用 `experimental_candidate_entry_gate: false` 的 configured 探针复核。

静态指标包括保持阶段机身倾角、双脚接触比例、质心投影到当前足底接触凸包的最小边界距离。这个几何指标只是静态诊断；动态平衡还涉及压力中心、接触力和动量，原理可参考 [MIT Underactuated Robotics 的 humanoid balance 讲义](https://underactuated.mit.edu/humanoids.html)。

## 保持时长和朝向复核

第一轮加 6 组复核，组合使用 stand 1/3/5 秒、准备后保持 1/10/30 秒、yaw 0/0.8/-1.2。三个候选均完成了全部 7 组的准备/保持阶段，双脚接触比例 100%。default_q 保持最大倾角 3.25°，最小质心边界余量 5.83 cm。

| 候选 | 这 7 组的整段播放完成数 |
| --- | --- |
| default_q | 5/7 |
| 中间蹲姿 | 5/7 |
| AMP 腿 + 微弯臂 | 3/7 |

default_q 的两组失败均是准备后只保持 1 秒的实验，分别触发关节限位和锚点误差保护。这不能推出所有较长保持都必然成功，也不能将样本完成比例当作真机成功概率。保留默认阈值，没有为通过实验放宽限制。

自动接管复核中，连续等待 3 秒在 yaw=-1.2 时第 153 拍触发锚点保护；4 秒候选在 yaw=0/0.8/-1.2 三组均完成 647 拍，因此当前选择 4 秒。记录在 `guide_auto_start/`，保留失败与候选来源。上述 6 组手动保持数据不代表当前自动接管通过。所有物理探针均从已站立状态开始，不涵盖 A 零位及 B 进入 stand 的实际物理过程；旧 `three_button_flow/` 作为历史流程保留。

这仍不能替代 Ubuntu 原生构建、C++ 测试、真实状态估计、执行器内部环与真机吊架验收。训练 default_q 是名义姿态/动作偏置，实际训练 reset 则从运动中采样并带非零速度；静态准备位可保持，并不表示完全复现了训练初始动态状态。短保持下的接管敏感性仍需继续实机核对。
