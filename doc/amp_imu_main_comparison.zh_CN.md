# 从 main 已验证的 12DOF 部署推断 AMP 的 IMU

在 IMU 安装、固件和启动方式未改变的前提下，main 的 12DOF 策略已真机稳定行走，是 IMU 主要轴向、符号和单位可用的重要证据。代码对照没有发现 AMP 新增了 IMU 轴互换或方向翻转。因此，大幅安装方向错误应降低排查优先级；保留已验证映射，优先检查当前全身反馈、执行器响应与姿态差异。

该推断不能证明 IMU 绝对水平误差为零，也不能验证新增腰部的机械零位。此前“胸部前倾约 7.1°”仍是基于模型坐标的几何估计，但不应仅因代码没有外参补偿，就推断当前 IMU 安装错误。

没有切换工作分支或修改 IMU 运行逻辑。证据及输入哈希见 [imu_main_comparison.json](analysis/amp_20261013/imu_main_comparison.json)。

**部署链路相同的部分**

| 项目 | main 与 AMP 的对照结果 |
|---|---|
| IMU 来源 | 同为 `imu_dcu_name: hip`，数据发布 1000 Hz |
| 角速度轴 | gyro[0/1/2] → x/y/z，没有交换或取反 |
| 角速度单位 | 同为度/秒 → 弧度/秒，乘 `π/180` |
| 四元数 | 同为 quat[0/1/2/3] → w/x/y/z |
| 安装外参 | 两者都没有额外软件安装旋转 |
| ApplyDcuImuOffset | 两者实现都为空；是已有行为，不是 AMP 新引入的问题 |

三个版本中，DCU 发布 IMU 的转换代码块 SHA256 完全一致。四元数和角速度是否已在固件侧转换到骨盆坐标，仍需固件/安装信息确认；但同样的链路曾用于 main 的闭环。

**训练与观测约定**

12DOF 训练在 `humanoid/envs/base/legged_robot.py` 中从根节点四元数得到姿态，并用 `quat_rotate_inverse(base_quat, world_ang_vel)` 得到身体坐标角速度。策略的后 6 个观测是身体角速度和 `[roll, pitch, yaw]`，均为弧度制。部署 main 的 `QuatToXyz` 与这一 roll/pitch/yaw 公式一致。

AMP 训练配置 `amp_env_cfg.py` 改用身体角速度及 `projected_gravity`。参考 sim2sim 明确计算 `gravity_body = R.T @ [0,0,-1]`，与当前部署 `quat.conjugate() * gravity_vector` 的方向一致。AMP 没有将 roll、pitch 的正方向改成另一套物理坐标。

对比实际加载的 URDF：12DOF 的 `resources/robots/x1/urdf/x1.urdf` 与 AMP 的 `roboparty_train/robolab/data/robots/x1/urdf/f1.urdf` 都以 `base_link` 为根；base 视觉 origin 均为 `rpy=0 0 0`，左右 hip pitch 的 parent、origin 和 axis 完全相同。没有发现根坐标相差 90°/180°的改动。这个检查不代表两模型全部动力学参数一致。

**重力向量计算变化是否引入符号错误**

main 先将四元数转成 ZYX 欧拉角，再构造旋转矩阵，取逆后乘 `[0,0,-1]`。AMP 归一化四元数后直接取共轭旋转重力。对单位四元数，两种计算等价，都是把世界重力表达在身体坐标。

用两次 AMP 实机日志逐帧核对，两种结果最大分量差分别约 `1.58×10⁻⁷`，不是足以解释数度倾斜的变化。日志中的 pitch 与独立标准公式重算也一致。因此，AMP 新使用的重力向量计算没有表现出前后翻转或轴序错误。

**该证据如何改变排查顺序**

1. 保留 main 已验证的 IMU 轴映射和单位转换。当前没有支持翻转 pitch、交换 X/Y 或修改四元数顺序的证据。
2. 不把 ApplyDcuImuOffset 空实现认定为 AMP 特有根因。贸然补上固件姿态重置可能改变原先可用的参考，需先确认该固件命令的语义。
3. 先处理已确定的左臂旧反馈、左膝动态超调、踝目标裁剪及髋膝相位差。全身动作和接触会改变骨盆真实姿态。
4. 胸部估计的剩余校准需求缩小为：同一套硬件下做可重复静态骨盆水平外测，再核对腰部反馈为零时的胸部相对骨盆机械角度。main 的旧策略不依赖新增腰 pitch 反馈，main 成功不验证该零位。
5. 若能取得已验证 0.6 m/s 那次的 zero/stand/行走日志，直接用同一公式比较静态 pitch 基准与运动变化，可进一步区分固定误差和 AMP 下的真实姿态变化。
